# 🎁 Secret Santa

A cozy, mobile-first Secret Santa web app: log in with email, phone or Google, create or join a group with a code or link,
share wishlists, and get a fun animated reveal of who you're gifting, with anonymous Santa ⇄ giftee chat.

Static site (GitHub Pages) + Supabase backend. The draw happens on the server, and each player can only ever fetch their own giftee.

Configure `js/config.js` with your Supabase project URL and anon key.
